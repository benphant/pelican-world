# Changelog

All notable changes to the Pelican World agent skill and tutorial are
documented here. The playable game is a separate work and is not
versioned in this file.

## 0.1.0 — 2026-11-16

First packaged skill and tutorial for the public repository
https://github.com/benphant/pelican-world. These files are on a branch
from `main`. The default branch contains the skill only after that
branch is merged. Install commands against `main` are not recorded
here as a completed install.

- Repository URL filled in. Earlier "repository not created" warnings
  removed. Launch texts in `marketing/` remain unpublished drafts.
- Skill entry: `pelican-world/SKILL.md` with progressive reference files.
- Method documented from the author's Pelican World v3 methodology notes
  (architecture, lighting, animation, materials, world building, audio,
  UI, testing, and a generic publishing guide).
- Project-specific protection configuration, host-lock details, and
  fingerprint or seed values from those notes are omitted.
- Size record for the public playable build and the documented
  unprotected size: see `pelican-world/examples/pelican-world/SIZE.md`.
- The game client, game source, and any third-party reference demo are
  not included. The playable game remains all-rights-reserved and is
  linked at https://pelican-world.vercel.app/
